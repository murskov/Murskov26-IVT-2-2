# Мурсков Роман 26-ИВТ-2-2
# Учет клиентов турфирмы
## Предметная область
Информационная система «Учёт клиентов турфирмы» предназначена для хранения и обработки информации о клиентах туристической фирмы, оформленных туристических путёвках и процессе бронирования туров.
В работе турфирмы ежедневно появляются новые клиенты, которые обращаются за подбором туристических поездок. Менеджер должен хранить персональные данные клиентов, подбирать подходящие туры, оформлять заявки, отслеживать статус бронирования и при необходимости изменять информацию о клиенте или его заказе.
Использование информационной системы позволяет отказаться от ведения информации в бумажном виде или в разрозненных таблицах, упрощает поиск клиентов и ускоряет оформление туристических услуг.
## Цель системы
Цель информационной системы — автоматизировать учёт клиентов турфирмы и процесс оформления туристических путёвок.
Для достижения этой цели система должна решать следующие задачи:
 - хранить информацию о клиентах;
- регистрировать новых клиентов;
 - искать клиента по персональным данным;
 - оформлять туристические путёвки;
 - изменять сведения о клиентах и оформленных турах;
 - хранить историю оформленных заявок.

### Пользователи системы
В информационной системе предусмотрено два пользователя, которые выполняют разные функции.
Менеджер турфирмы работает непосредственно с клиентами. Он регистрирует новых клиентов, выполняет поиск клиентов в базе данных, оформляет туристические путёвки и просматривает список оформленных заявок. Администратор системы отвечает за сопровождение информационной системы и управление данными. Он редактирует сведения о клиентах, удаляет ошибочные записи, изменяет статус туристических путёвок и просматривает полный список клиентов и оформленных путёвок.

### Основные функции системы
Информационная система должна выполнять следующие функции:
1. Регистрация нового клиента.
2. Поиск клиента по персональным данным.
3. Просмотр списка клиентов.
4. Оформление туристической путёвки.
5. Редактирование данных клиента.
6. Удаление ошибочной записи клиента.
7. Просмотр списка туристических путёвок.
8. Изменение статуса туристической путёвки.

## Архитектура и способ реализации
Для разработки проекта выбрана трёхуровневая многослойная архитектура (Layered Architecture). Она разделяет систему на три независимых слоя.
Presentation Layer — пользовательский интерфейс, через который менеджер и администратор работают с системой.
Business Logic Layer — обработка действий пользователей, проверка корректности данных и выполнение бизнес-логики.
Data Layer — хранение информации о клиентах и туристических путёвках в базе данных.
